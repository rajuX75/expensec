Why users aren't seeing your notification

  • ❌ Write failed silently due to Firebase rules (most common)
  • ❌ active field is false or missing from the node
  • ❌ title field is blank or missing
  • ❌ showPopup: false → shows in inbox only, NOT as popup
  • ❌ User already dismissed this notification ID (stored per-device)
  • ❌ Notification ID was reused — previous dismissal blocks it
  • ❌ App needs to be reopened after you publish (real-time listener picks it up)

Required fields checklist

{
  "id":         "notif_001",   ← must match node key
  "title":      "Hello!",      ← required, not blank
  "active":     true,          ← required, set to true
  "timestamp":  1725000000000  ← Unix ms for sort order
}
